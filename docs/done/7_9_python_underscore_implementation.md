## 섹션별 구현 사항

### # 1. 들어가며

- 언더스코어가 Python에서 특별한 이유 간략 소개
- 6가지 주요 용법 요약 리스트 제시

### # 2. 변수로서의 언더스코어 (`_`)

- **2.1 REPL 마지막 결과값**: Python 인터프리터에서 `_`가 마지막 표현식 결과를 저장하는 예제
- **2.2 무시 변수**: `for _ in range()`, 튜플 언패킹 `x, _, z = (1, 2, 3)` 예제
- **2.3 국제화(i18n)**: `gettext` 모듈의 `_()` 함수 별칭 사용 예제

### # 3. 네이밍 컨벤션에서의 언더스코어

- **3.1 `_name` 선행 단일 언더스코어**
  - 클래스/모듈 내부 변수 표시 예제
  - `from module import *` 시 `_`로 시작하는 이름이 제외되는 것을 보여주는 예제 (모듈 2개 구성)
  - `__all__` 리스트와의 우선순위 관계 설명
- **3.2 `name_` 후행 단일 언더스코어**
  - `class_`, `type_`, `list_` 등 키워드 충돌 방지 예제
  - PEP 8 관련 인용

### # 4. Name Mangling (`__name`)

- 클래스 내부에서 `__var` 선언 → `_ClassName__var`로 변환되는 예제
- 상속 구조에서 부모/자식 클래스 간 이름 충돌 방지 예제
- `dir(obj)`로 mangled 이름 확인 예제
- 사용 시 주의사항 (남용 금지, 의도적 사용 가이드)

### # 5. 던더 메서드와 속성 (`__name__`)

- **5.1 매직 메서드 카테고리별 예제**
  - 생성/초기화: `__init__`, `__new__`
  - 문자열 표현: `__repr__`, `__str__`
  - 비교: `__eq__`, `__lt__`
  - 산술 연산: `__add__`, `__mul__`
- **5.2 매직 속성**: `__name__`, `__doc__`, `__module__`, `__class__` 출력 예제
- **5.3 `if __name__ == "__main__":` 패턴**: 모듈 직접 실행 vs import 시 동작 차이 예제

### # 6. 숫자 리터럴에서의 언더스코어 (`1_000_000`)

- 10진수 자릿수 구분: `1_000_000`
- 16진수: `0xFF_FF`, 2진수: `0b1111_0000`, 8진수: `0o1_234`
- 잘못된 사용 예시 (시작/끝/연속 위치 불가) → SyntaxError

### # 7. 실전 비교표 및 주의사항

- `_var` vs `__var` vs `__var__` 비교표 (마크다운 테이블)
  - 패턴 | 이름 | 의미 | 접근 가능 여부 | 사용 시점
- 판단 기준 플로우 설명
- 흔한 실수와 안티패턴 (ex. 던더 메서드 직접 정의 시 예약어 충돌)
