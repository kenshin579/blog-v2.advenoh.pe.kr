#### A. ~합니다 계열 (동사 현재형)

#### B. ~됩니다 계열 (피동형)

#### D. ~습니다 계열 (형용사/동사 과거형 등)
- 있습니다, 없습니다, 좋습니다, 어렵습니다, 중요합니다 등
- **변환 규칙**:
  - `있습니다` -> `있다`
  - `없습니다` -> `없다`
  - `않습니다` -> `않는다`
  - `좋습니다` -> `좋다`
  - `어렵습니다` -> `어렵다`

## 3. 변환 규칙 정의

### 3.1 정규식 기반 변환 규칙

```python
CONVERSION_RULES = [
    # ~습니다 계열 (특수 케이스 먼저)
    (r'있습니다', '있다'),
    (r'없습니다', '없다'),
    (r'않습니다', '않는다'),
    (r'좋습니다', '좋다'),
    (r'높습니다', '높다'),
    (r'낮습니다', '낮다'),
    (r'많습니다', '많다'),
    (r'같습니다', '같다'),

    # ~았/었습니다 계열 (과거형)
    (r'았습니다', '았다'),
    (r'었습니다', '었다'),

    # 기본 패턴 (우선순위 낮음)
    (r'합니다', '한다'),
    (r'됩니다', '된다'),
    (r'입니다', '이다'),
]
```

### 3.2 변환 우선순위
1. 긴 패턴 먼저 매칭 (예: `있습니다` -> `있다`)
2. 짧은 패턴 나중에 매칭 (예: `합니다` -> `한다`)

## 4. 구현 방안

### 4.1 Python 스크립트 사용

```python
#!/usr/bin/env python3
import re
from pathlib import Path

CONVERSION_RULES = [
    # ~습니다 계열 (특수 케이스 먼저)
    (r'있습니다', '있다'),
    (r'없습니다', '없다'),
    (r'같습니다', '같다'),
    (r'않습니다', '않는다'),
    (r'좋습니다', '좋다'),
    (r'많습니다', '많다'),
    (r'높습니다', '높다'),
    (r'낮습니다', '낮다'),

    # ~았/었습니다 계열 (과거형)
    (r'았습니다', '았다'),
    (r'었습니다', '었다'),

    # 기본 패턴 (우선순위 낮음)
    (r'합니다', '한다'),
    (r'됩니다', '된다'),
    (r'입니다', '이다'),
]

def convert_file(file_path: Path) -> bool:
    """파일의 높임말을 짧은 표현으로 변환"""
    content = file_path.read_text(encoding='utf-8')
    original = content

    for pattern, replacement in CONVERSION_RULES:
        content = re.sub(pattern, replacement, content)

    if content != original:
        file_path.write_text(content, encoding='utf-8')
        return True
    return False

def main():
    contents_dir = Path('contents/database')
    modified_count = 0

    for md_file in contents_dir.glob('mqtt-v5-guide-*/index.md'):
        if convert_file(md_file):
            print(f'Modified: {md_file}')
            modified_count += 1

    print(f'\nTotal modified files: {modified_count}')

if __name__ == '__main__':
    main()
```
