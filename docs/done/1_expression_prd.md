# 높임말 -> 짧은 표현 변환 PRD

## 1. 개요

### 1.1 목적
contents 폴더의 마크다운 파일들에서 높임말(존댓말/합쇼체) 표현을 짧은 표현(해라체/평서형)으로 일괄 변환하여 블로그 문체를 통일한다.

### 1.2 범위
- **대상 폴더**: `contents/`
- **대상 파일**: `index.md`
- **전체 파일 수**: 143개
- **변환 대상 파일 수**: 83개 (높임말 패턴이 존재하는 파일)
- **총 변환 대상 패턴 수**: 약 912개
- **고유 패턴 수**: 300개

### 1.3 제외 대상
- `~요`로 끝나는 표현 (예: ~세요, ~주세요, ~해주세요 등)은 변환하지 않음

### 2.2 패턴 카테고리별 분류

#### A. ~합니다 계열 (동사 현재형)
- 생성합니다, 사용합니다, 제공합니다, 저장합니다, 추가합니다, 실행합니다, 삭제합니다 등
- **변환 규칙**: `합니다` -> `한다`

#### B. ~됩니다 계열 (피동형)
- 사용됩니다, 생성됩니다, 실행됩니다, 호출됩니다, 저장됩니다 등
- **변환 규칙**: `됩니다` -> `된다`

#### C. ~입니다 계열 (명사+서술격 조사)
- 예제입니다, 자료입니다, 메서드입니다, 방식입니다, 것입니다 등
- **변환 규칙**: `입니다` -> `이다`

#### D. ~습니다 계열 (형용사/동사 과거형 등)
- 있습니다, 없습니다, 같습니다, 좋습니다, 되었습니다, 했습니다 등
- **변환 규칙**:
  - `있습니다` -> `있다`
  - `없습니다` -> `없다`
  - `같습니다` -> `같다`
  - `되었습니다` -> `되었다`
  - `했습니다` -> `했다`
  - `않습니다` -> `않는다`

#### E. ~겠습니다 계열 (의지/추측)
- 알아보겠습니다, 하겠습니다, 보겠습니다 등
- **변환 규칙**: `겠습니다` -> `자` 또는 문맥에 따라 조정

## 3. 변환 규칙 정의

### 3.1 정규식 기반 변환 규칙

```python
CONVERSION_RULES = [
    # ~합니다 계열
    (r'합니다', '한다'),

    # ~됩니다 계열
    (r'됩니다', '된다'),

    # ~입니다 계열
    (r'입니다', '이다'),

    # ~습니다 계열 (특수 케이스 먼저)
    (r'있습니다', '있다'),
    (r'없습니다', '없다'),
    (r'같습니다', '같다'),
    (r'않습니다', '않는다'),
    (r'봤습니다', '봤다'),
    (r'했습니다', '했다'),
    (r'왔습니다', '왔다'),
    (r'졌습니다', '졌다'),
    (r'났습니다', '났다'),
    (r'렸습니다', '렸다'),
    (r'였습니다', '였다'),
    (r'웠습니다', '웠다'),

    # ~겠습니다 계열
    (r'보겠습니다', '보자'),
    (r'하겠습니다', '하자'),
    (r'알아보겠습니다', '알아보자'),
]
```

### 3.2 변환 우선순위
1. 긴 패턴 먼저 매칭 (예: `알아보겠습니다` -> `알아보자`)
2. 짧은 패턴 나중에 매칭 (예: `합니다` -> `한다`)

## 4. 구현 방안

### 4.1 Python 스크립트 사용

```python
#!/usr/bin/env python3
import re
from pathlib import Path

CONVERSION_RULES = [
    # 긴 패턴 먼저 (우선순위 높음)
    (r'알아보겠습니다', '알아보자'),
    (r'해보겠습니다', '해보자'),
    (r'살펴보겠습니다', '살펴보자'),
    (r'확인해보겠습니다', '확인해보자'),
    (r'조회해보겠습니다', '조회해보자'),

    # ~겠습니다 계열
    (r'겠습니다', '자'),

    # ~았/었습니다 계열 (과거형)
    (r'았습니다', '았다'),
    (r'었습니다', '었다'),

    # ~습니다 계열
    (r'있습니다', '있다'),
    (r'없습니다', '없다'),
    (r'같습니다', '같다'),
    (r'않습니다', '않는다'),
    (r'좋습니다', '좋다'),
    (r'많습니다', '많다'),
    (r'높습니다', '높다'),
    (r'낮습니다', '낮다'),

    # 기본 패턴 (우선순위 낮음)
    (r'합니다', '한다'),
    (r'됩니다', '된다'),
    (r'입니다', '이다'),
]

def convert_file(file_path: Path) -> bool:
    """파일의 높임말을 짧은 표현으로 변환"""
    content = file_path.read_text(encoding='utf-8')
    original = content

    for pattern, replacement in CONVERSION_RULES:
        content = re.sub(pattern, replacement, content)

    if content != original:
        file_path.write_text(content, encoding='utf-8')
        return True
    return False

def main():
    contents_dir = Path('contents')
    modified_count = 0

    for md_file in contents_dir.rglob('index.md'):
        if convert_file(md_file):
            print(f'Modified: {md_file}')
            modified_count += 1

    print(f'\nTotal modified files: {modified_count}')

if __name__ == '__main__':
    main()
```
