# 블로그 콘텐츠 목차 스타일 Skill PRD

## 1. 개요

### 1.1 목적
`contents/` 및 `docs/start/` 디렉토리에 새로운 블로그 글(index.md)을 작성하거나 기존 글을 수정할 때, **목차(Heading) 번호 스타일을 자동으로 일관성 있게 유지**하는 Claude Code Skill을 만든다.

### 1.2 배경
- 블로그에 100개 이상의 글이 존재하며, 대부분 일관된 번호 체계를 사용
- 새 글 작성 시 번호 체계를 수동으로 관리하면 누락이나 불일치가 발생
- 기존에 `4_content_prd.md`에서 MQTT 가이드 목차 스타일 통일 작업을 수동으로 진행한 전례가 있음
- Skill로 자동화하면 모든 콘텐츠에 일관성을 보장할 수 있음

### 1.3 범위
- **Skill 파일 생성**: `.claude/skills/content-heading-style/SKILL.md`
- **적용 대상**: `contents/**/index.md`

## 2. 목차 스타일 규칙

### 2.1 Heading 번호 체계

| 레벨 | 마크다운 | 형식 | 예시 |
|------|---------|------|------|
| H1 | `#` | `# N. 제목` | `# 1. 들어가며` |
| H2 | `##` | `## N.M 제목` | `## 1.1 Topic 구조` |
| H3 | `###` | `### N.M.K 제목` | `### 1.1.1 계층적 네이밍` |

### 2.2 번호 규칙 상세

1. **H1 번호**: 1부터 시작, 순차 증가
   ```markdown
   # 1. 들어가며
   # 2. 개발 환경
   # 3. 본문 주제
   # 4. 마무리
   # 5. 참고
   ```

2. **H2 번호**: 상위 H1 번호 + 순차 번호
   ```markdown
   # 3. 본문 주제
   ## 3.1 첫 번째 소주제
   ## 3.2 두 번째 소주제
   ```

3. **H3 번호**: 상위 H2 번호 + 순차 번호
   ```markdown
   ## 3.1 첫 번째 소주제
   ### 3.1.1 세부 항목 A
   ### 3.1.2 세부 항목 B
   ```

### 2.3 잘못된 패턴 (검출 대상)

| 잘못된 패턴 | 올바른 패턴 |
|------------|-----------|
| `# 제목` (번호 없음) | `# 1. 제목` |
| `# 0장. 제목` | `# 1. 제목` |
| `# X장. 제목` | `# X. 제목` |
| `## 제목` (번호 없음) | `## 1.1 제목` |
| `### 제목` (번호 없음) | `### 1.1.1 제목` |
| `# 1.제목` (공백 없음) | `# 1. 제목` |

### 2.4 예외 사항
- YAML frontmatter (`---` 블록) 내부는 변환 대상이 아님
- 코드 블록(``` ```) 내부의 `#`은 heading이 아님
- 주석이나 설명 목적의 `#`은 무시

## 3. Skill 구현 요구사항

### 3.1 Skill 파일 구조

```
.claude/skills/content-heading-style/
├── SKILL.md              # Skill 정의 파일
└── references/
    └── heading-rules.md  # 상세 규칙 참조 문서
```

### 3.2 SKILL.md 프론트매터

```yaml
---
name: content-heading-style
description: 블로그 콘텐츠(index.md)의 목차 Heading 번호 스타일 일관성을 유지한다. contents/ 디렉토리의 index.md 파일을 작성하거나 수정할 때 자동으로 활성화된다.
---
```

### 3.3 Skill 동작 정의

Skill이 활성화되면 다음을 수행:

1. **검증 모드**: 대상 파일의 heading 번호 체계가 올바른지 검사
   - 번호 누락, 순서 오류, 형식 불일치 검출
   - 문제가 있는 heading 목록 출력

2. **수정 모드**: 잘못된 heading 번호를 올바른 형식으로 변환
   - 기존 번호 체계를 파일 내 순서에 맞게 재정렬
   - 번호 없는 heading에 번호 추가
   - `X장.` 형식을 `X.` 형식으로 변환

### 3.4 검증 명령 예시

```bash
# Heading 패턴 확인 (올바른 형식만 존재해야 함)
grep -E "^# [0-9]+\. " target_file.md
grep -E "^## [0-9]+\.[0-9]+ " target_file.md
grep -E "^### [0-9]+\.[0-9]+\.[0-9]+ " target_file.md

# 잘못된 패턴 검출 (결과가 없어야 정상)
grep -E "^# [^0-9]" target_file.md          # 번호 없는 H1
grep -E "^## [^0-9]" target_file.md          # 번호 없는 H2
grep -E "^### [^0-9]" target_file.md         # 번호 없는 H3
grep -E "^# [0-9]+장\." target_file.md       # "X장." 형식
```

## 4. 활용 시나리오

### 4.1 새 글 작성 시
- Claude에게 블로그 글 작성을 요청하면, Skill이 자동으로 활성화되어 올바른 heading 번호 체계로 작성

### 4.2 기존 글 수정 시
- heading을 추가/삭제/이동하면, Skill이 전체 번호 체계를 재정렬

### 4.3 일괄 검증 시
- 특정 디렉토리의 모든 index.md 파일에 대해 heading 스타일 일관성 검사

| 순서 | 작업 | 설명 |
|------|------|------|

| 2 | SKILL.md 작성 | 프론트매터 + 시스템 프롬프트 작성 |

| 4 | 동작 검증 | 기존 글에 대해 Skill 동작 확인 |
