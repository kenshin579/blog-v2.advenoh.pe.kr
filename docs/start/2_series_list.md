## 문서 구조

이 기능은 다음 3개 문서로 구성되어 있습니다:

1. **[요구사항 (PRD)](./2_series_navigation_prd.md)**
   - 기능 목적 및 요구사항
   - UI/UX 정의
   - 현재 상태 분석

2. **[구현 가이드](./2_series_navigation_implementation.md)**
   - SeriesNavigation 컴포넌트 구현
   - Article Page 수정 방법
   - 코드 예시

3. **[작업 체크리스트](./2_series_navigation_todo.md)**
   - Phase별 구현 단계
   - 테스트 항목
   - 마무리 작업
