# PRD: Python 패턴 매칭 (match/case)

## 개요
Python 3.10+ structural pattern matching의 문법과 실전 활용 사례를 다루는 블로그 포스팅.

## 시리즈
- **시리즈**: Python 핵심 문법 마스터
- **번호**: 2-6
- **난이도**: 중급
- **우선순위**: ★☆☆

## 다룰 내용
1. match/case 기본 문법
2. 리터럴 패턴, 캡처 패턴, 와일드카드 패턴
3. 시퀀스 패턴, 매핑 패턴
4. 클래스 패턴
5. OR 패턴 (`|`)
6. guard 조건 (`if`)
7. 중첩 패턴
8. 실전 활용: 커맨드 파서, 상태 머신, JSON 데이터 처리
9. if/elif vs match/case 비교
