# PRD: Python 언더스코어의 모든 것

## 개요
Python에서 언더스코어(`_`)의 다양한 용법과 컨벤션을 정리하는 블로그 포스팅.

## 다룰 내용

### # 1. 들어가며
- Python에서 언더스코어(`_`)가 사용되는 다양한 맥락 소개
- 언더스코어 용법 전체 개요

### # 2. 변수로서의 언더스코어 (`_`)
- 2.1 REPL에서 마지막 결과값 저장: `>>> 1 + 2` → `>>> _`
- 2.2 무시 변수: `for _ in range(10):`, `x, _, z = tuple`
- 2.3 국제화(i18n) 관례: `_("Hello")` → gettext 함수 별칭

### # 3. 네이밍 컨벤션에서의 언더스코어
- 3.1 `_name` 선행 단일 언더스코어 (내부 사용 컨벤션)
  - "내부 구현" 표시: 외부에서 접근 가능하지만 접근하지 말라는 의미
  - `from module import *` 시 제외됨
  - `__all__`과의 관계
- 3.2 `name_` 후행 단일 언더스코어 (키워드 충돌 방지)
  - `class_`, `type_`, `list_` 등 Python 키워드와 충돌 시 사용
  - PEP 8 공식 가이드라인

### # 4. Name Mangling (`__name`)
- `_ClassName__name`으로 이름이 변환되는 원리
- 상속 시 이름 충돌 방지 목적
- `dir(obj)`로 mangled 이름 확인
- 의도적 사용 vs 남용 주의

### # 5. 던더 메서드와 속성 (`__name__`)
- 5.1 주요 매직 메서드 카테고리: 생성(`__init__`), 표현(`__repr__`, `__str__`), 비교(`__eq__`, `__lt__`), 연산(`__add__`)
- 5.2 주요 매직 속성: `__name__`, `__doc__`, `__module__`, `__class__`
- 5.3 `if __name__ == "__main__":` 패턴의 동작 원리

### # 6. 숫자 리터럴에서의 언더스코어 (`1_000_000`)
- Python 3.6+ 기능: 가독성 향상을 위한 자릿수 구분
- 16진수/2진수에서도 사용: `0xFF_FF`, `0b1111_0000`
- 위치 제한: 시작/끝/연속 불가

### # 7. 실전 비교표 및 주의사항
- `_var` vs `__var` vs `__var__` 한눈에 비교표
- 언제 `_`를 쓰고 언제 `__`를 쓰는지 판단 기준
- 흔한 실수와 안티패턴
