# 시리즈 네비게이션 기능 요구사항

## 목적

같은 시리즈로 묶인 아티클 페이지에서 시리즈 내 모든 아티클 목록을 표시하고, 현재 보고 있는 아티클을 시각적으로 표시한다.

## 요구사항

### 기능 요구사항

1. **시리즈 목록 표시**
   - 아티클이 시리즈에 속한 경우, 같은 시리즈의 모든 아티클 목록을 표시
   - 생성 날짜(date) 순서대로 정렬하여 표시 (오래된 글부터)
   - 시리즈 이름을 상단에 표시

2. **현재 아티클 표시**
   - 현재 보고 있는 아티클을 왼쪽 화살표(`←`)로 표시
   - 현재 아티클은 굵은 글씨로 강조

3. **네비게이션**
   - 다른 아티클 제목을 클릭하면 해당 아티클로 이동
   - 현재 아티클은 클릭 불가능한 텍스트로 표시

### UI 요구사항

**표시 위치**: 아티클 헤더와 본문 사이

**UI 구조**:
```
┌─────────────────────────────────────────┐
│ 📚 시리즈: Spring JPA                    │
├─────────────────────────────────────────┤
│ 1. JPA 일대일 @One-To-One 연관관계       │
│ 2. JPA 연관관계 매핑 정리                │
│ 3. JPA 다대일 @Many-To-One 연관관계   ← │
│ 4. JPA N+1 문제 해결방법                 │
└─────────────────────────────────────────┘
```

**스타일**:
- shadcn/ui Card 컴포넌트 사용
- 다크모드 지원
- 반응형 디자인

### 조건부 표시

- 아티클에 `series` 필드가 있을 때만 표시
- 시리즈에 2개 이상의 아티클이 있을 때만 표시

## 현재 상태

### 데이터 구조 (이미 존재)

**위치**: `lib/articles.ts`

```typescript
interface ManifestArticle {
  series?: string;  // 시리즈 이름
  date: string;     // 생성 날짜 (정렬 기준)
}
```

**기존 함수**:
- `getArticlesBySeries(series: string)`: 시리즈별 아티클 반환 (날짜순 정렬 필요)

### 아티클 페이지 구조

**위치**: `app/[slug]/page.tsx`

현재 아티클 페이지에는 시리즈 네비게이션이 없음.

## 예상 파일 변경
